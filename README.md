## Mi perspectiva de la privacidad actual.

Vivir ultimamente se **siente como si absolutamente todos te estuvieran observando en cada accion que tomas** en internet, la batalla de la privacidad se perdio hace mucho tiempo, sin embargo, siempre existe asi sea un poco de esperanza con respecto a buscar los derechos que merecemos. 

Siento que dentro de poco tiempo la gente se dara cuenta que **se le esta observando de forma descarada en aspectos tan personales y vulnerables de su vida** que eventualmente tendran que aprenderse asi sea a resguardarse de forma minima. Aqui es donde presiento que la ciberseguridad capaz tiene algo que ver en la vida de un "average joe".

## Entornos de aprendizaje:

Lista de plataformas que utilizo para informarme de vulnerabilidades

*   🐳 **[DockerLabs](https://dockerlabs.es/):** Muy util para practicar Privilege escalation, Entornos en contenedores muy faciles de desplegar y de explotar, muy buenos para empezar.
*   🟩 **[HackTheBox (HTB)](https://www.hackthebox.com/):** Labs un poco mas realistas y complejos, muy bueno si se desea profundizar en arquitecturas especificas.
*   🚩 **[TryHackMe (THM)](https://tryhackme.com/):** Realmente este es el que menos utilizo, sin embargo tiene dinamicas muy interesantes para empezar, con metodologias tipo CTF.
*   🕸️ **[PortSwigger Web Security Academy](https://portswigger.net/web-security/all-labs):** Todo de vulnerabilidades web (SQLi, XSS, SSRF, etc.) desarrolladas por los creadores de Burp Suite.
